# White Canvas

Private working repository for the film concept **White Canvas**.

The current draft is intentionally a **story sketch, not a locked screenplay**. It preserves the forward-only knowledge rule: characters may react only to concepts that have actually emerged in their world at that point in the film.

## Current material

- [`script/WHITE_CANVAS_v0.1.md`](script/WHITE_CANVAS_v0.1.md) — first aligned story sketch, dialogue anchors, character rules, continuity law, and thematic spine.

## Working principle

Do not polish individual scenes faster than the full causal arc can support them. The next pass should test the story continuously from the opening white canvas to the final black canvas, then refine dialogue, pacing, image, sound, and production language without leaking later knowledge into earlier scenes.
